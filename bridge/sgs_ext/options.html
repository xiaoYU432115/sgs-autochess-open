设置

开着时页面每 20 秒 / 后台每分钟从助手拉一次规则。关掉后只剩「总览」里的「立即同步」和打开游戏页时的一次性同步。

关掉后角标清空（暂停状态仍会显示 off）。

关掉 = 一个脚本都不注入（含主脚本／桥接），已注册的全部撤销。
⚠ 两件事要说清楚：
① 这跟「总览」页那个「暂停/启用」不是一回事 —— 那个只撤网络重定向规则，脚本照跑；这个才是真停脚本。
② userScripts 的撤销只对之后新开的页面生效；已经打开的游戏页里脚本还在跑，要刷新一次页面才彻底停。
③ 主脚本（桥接）停掉后，助手就读不到游戏数据了 —— 想让助手干活就得开着。

在「总览」页改 —— 那里能看到改完后的规则地址，方便确认。

这些设置只影响本扩展；助手里那套（剧本、决策、资源规则）照旧在助手自己的界面上配。

这个扩展里装了什么

一份顶两份 —— 装这一个就不用再装 Tampermonkey，也不用装 GoRes：
能力在哪一层覆盖
油猴脚本本体页面层（world:"MAIN" 注入，同一份代码）收发协议 / 剧本 / 看牌 / 换肤的页面 hook
GoRes 同款重定向网络层（declarativeNetRequest）所有资源 —— 图集 .atlas、语音 .mp3 都能换
管理页（本页）—脚本管理 / 添加脚本 / 规则 / 挑官方立绘 / 设置 / 工具
页面层那套换肤 hook 会自己让位给网络层（读 <html data-sgs-res-ext> 标记）， 两层不会重复改写同一个请求。

规则从哪来

  • 助手下发：助手开着时自动从 /rules 同步（页面开着约 20 秒一次，页面没开最多 1 分钟一次）。
  • 手写：「规则」页自己加。存在浏览器本地，助手没开也生效，可导入导出。
  • 同一个匹配串两边都写了 → 手写的赢。

脚本管理怎么用

  • 添加脚本：「脚本」页 → 「＋ 添加脚本」粘贴代码，或把 .user.js 文件直接选进来。 带 ==UserScript== 头的自动取名字和 @match；没头的用默认游戏域。
  • 启停：每条脚本一个开关，停了立即从页面撤下（走 chrome.userScripts， 和 Tampermonkey 同一个 API）。内置主脚本除外 —— 它走 manifest 注入，最可靠，要停请停整个扩展。
  • 获取新脚本：「获取新脚本」页列的是助手自带的（/scripts.json）， 一键安装；主脚本标了「已内置」不用再装。别处的脚本文件拖进「脚本」页即可。
  • 导入/备份：「实用工具」页可以导出全部数据（规则+脚本+设置），换机/重装一次导回。

常见问题

  • 为什么有的规则没生效？ 总览「被跳过的」一栏会写原因：目标不是 http 地址 / 同一截 URL 配了两条 / 超出条数上限(900)。
  • 本地图怎么换？ 只能用「本机图片」模式（走助手 /img/），并把图放进助手的 我的图/ 目录。
  • 换季要重装吗？ 不用。规则自动跟助手走。
  • 和轻量版(res_ext)什么关系？ 轻量版只有网络层重定向，要配 Tampermonkey 才完整；本扩展一份全包。两个都装也不打架，但没必要。

边界

  • 只对资源 URL 做重定向，顶层文档导航永远不碰（不会"点进游戏变白屏"）。
  • 本机地址（127.0.0.1 / localhost）的请求不会被二次改写（防套娃）。
  • 规则来源只允许本机 —— 端口可改，host 不允许被填成外部地址。
